## Combust's calls, 2026-10-14

| question | answer |
|---|---|
| Transport | **The mute, shown as ▶/■, plus B1 hold.** The pattern stops, the clock runs on (a restart lands on the beat), keys still play. B1 held ≥ 600 ms and released with no pot turned and no B3 toggles it. |
| CV keymap | **One map, 0 V = key 0.** J4 = key: 0 V is key 0 (C1), chromatic up, negatives clamp to key 0, keys always from the Kit table. The J4 mute key and the Brain-map modifier keyswitches go (start/stop is the transport). J5 style gets a dead band. The page shows the live J4 → key. |
| Pads keys | **Automatic in Pads, a button elsewhere.** Markers in time order → keys 0, 1, 2… whenever markers change in Pads; a "markers → keys" op everywhere. Undoable. |
| Autoslice | **A count knob with randomness.** One pot on the Edit page sets how many markers; which onsets join or leave is a weighted random draw by salience, so each roll gives a different chop; a re-roll draws again. |

## What gets built

### 1. Ported from Kyklophoria (no player-facing change)

- **Link**: unplug detection (the read loop ending disconnects the page),
  `Link(transport)` with Serial / Fake transports, `bytesIn` / kbps stats.
- **Page**: the publish script stamps the commit into the footer and the
  script URLs; Connect shows "connecting…" and can't be double-pressed;
  messages expire unless they are faults; readouts clear on disconnect; a
  draw error shows on the message line; steady readouts (the pitch pill's
  smoothing + thresholds + tabular-nums) for BPM / jitter / load; contrast
  measured, every text colour ≥ 4.5:1.
- **Firmware**: DWT cycle accounting of the audio callback — average and
  peak per second as ‰ of the 24-sample budget (240 000 cycles at 480 MHz) —
  in the state tail; the CPU meter on the page reads it. One version string.
- **Tests**: the page harness gains an unknown-element-id trap, captured
  listeners + `fire()` so tests perform the real gesture, and draw logs so a
  check can assert what was drawn. A **descriptor-parity check**: demo.js's
  fields, labels, offsets and enums must equal the firmware's.
- **README** user-first: install, card, page, then the rest.

Deferred past the beta: the desktop `--serve` shell + shared StateExt
(plan C8, several days, needs its own hardware pass), golden renders,
`make armcost`, the panel mirror with settable pots (needs `host.Pages`).

### 2. Firmware for the bench report

- **Transport**: B1 hold (above). `ACTION 35 SET_MUTE` beside the toggle.
- **TAP_MARK** refuses when nothing sounds (BAD_STATE), and a tap within
  10 ms of a live marker selects that marker instead of stacking a new one.
- **KEYS_FROM_MARKERS** and **CLEAR_MARKERS**, one undo step each; Pads
  applies keys-from-markers automatically when markers change.
- **One CV keymap** (above).
- **AUTOSLICE(k)**: weighted sampling without replacement over the onsets
  (Efraimidis–Spirakis keys u^(1/w), w = salience), so for a fixed seed the
  k-marker set is nested in the (k+1)-marker set — turning the knob up adds
  the next drawn onset, down removes the last one. A re-roll is a new seed.
  On the panel: P5 in Edit; sweeping it to 0 and back re-rolls.
- **PLAY_KEY** for on-screen pads (down / up; held keys release on up).

### 3. The page revamp

A transport bar on every tab (▶/■ ≥ 48 px, BPM, lock, CPU, mode-aware
buttons — Play's Dice is the looper undo and its Reslice/Clear asks first);
mode chips up front on the Play tab, each saying which keymap and buttons it
implies; a Jacks card with the live J4 → key readout; on-screen pads; the
Kit editor's markers → keys, clear markers, the autoslice count with re-roll;
no grid ghosts in Play / Pads (call flashes drawn by key); Options regrouped
so nothing lands in "Other"; phone layout (scrolling nav, ≥ 44 px targets,
the transport within thumb reach); a light theme beside the dark one.

## Protocol additions (v0.13)

Descriptor capability bumps: `"edit":2` (TAP_MARK changed meaning), new
`"keys":1` (ACTIONs 32–36 and the tail from 263).

    0x63 ACTION
      29 TAP_MARK   as before, but BAD_STATE (3) when nothing sounds (tail 263 b0 clear),
                    and a mark within 10 ms of a live marker selects that marker:
                    reply u8 status, u8 tableGen, u8 idx, u8 flags (b0 = existing marker reused)
      32 PLAY_KEY   (u8 key 0..23, u8 down 1 / up 0) → u8 status. Plays the key as a CV
                    note would (plain style); an up releases a held key, a no-op for one-shot.
      33 KEYS_FROM_MARKERS ([u8 gen]) → u8 status, u8 tableGen, u8 count.
                    Live markers in time order → keys 0..; keys holding a recording are
                    skipped (kept). One undo step.
      34 CLEAR_MARKERS ([u8 gen]) → u8 status, u8 tableGen, u8 count. Every live marker
                    (grey and orange) tombstoned; their keys go back to their grid slices.
                    One undo step.
      35 SET_MUTE   (u8 1 stopped / 0 running) → u8 status.
      36 AUTOSLICE  (u8 k 0..64, u8 flags b0 re-roll [, u8 gen]) → u8 status, u8 tableGen,
                    u8 count. Grey markers replaced by the first k of the seeded draw;
                    orange (tapped) markers stay. k = 0 removes the grey markers.

    state tail (after 262 u8 redoDepth)
      263 u8  flags2   b0 srcValid (a voice sounds: TAP_MARK will be taken)
                       b1 keys follow markers (Pads with markers)
      264 u16 loadAvg  audio callback, ‰ of the block budget, mean over the last second
      266 u16 loadMax  ‰, peak over the last second
      268 i16 j4mV     J4 now, millivolts
      270 u8  j4Key    the key J4 would play now (0..23)
      271 u8  j5Style  Voice map: the style J5 reads now (0..8); 255 in the Brain map
      272 u8  keyFlash the last key called by any source (CV, page, panel), 255 none
      273 u8  keySeq   bumps on every key call
      274 u8  autoK    the autoslice count last applied (0 none)
      275 u8  nMarkers live markers
      ends at 276
