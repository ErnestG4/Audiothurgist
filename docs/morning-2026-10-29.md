## What's new since beta7

- **Bug fixes from a review** (each with a test unless noted):
  - **A short CV trigger left a key stuck on.** Held / Loop / Ratchet keys
    got their release before their call on triggers under ~2 ms. *Host-untested.*
  - **A key held from a page pad is released if the cable goes.** A
    1 s watchdog on the link. *Host-untested.*
  - **Releases can no longer be lost.** A page release and a CV gate fall
    used to overwrite each other.
  - **A ratchet stops when its key is re-pointed**, whatever re-points it.
  - **Loop:** a release at the loop point fades its full length instead of
    clicking, and re-striking a held Loop key replaces its loop instead of
    stacking a second.
  - **A Loop key whose Plays changed mid-loop** now stops on release.
  - **Edits are refused while a set load finishes**, so they can't be
    silently overwritten. *Host-untested.*
  - **A preset saved right after a sampler power-up keeps your drum
    grammar**, not Pads. *Host-untested.*
  - **Page:**
    - an Undo is no longer reverted by your next touch on the key row;
    - a change to a second key mid-send is no longer lost;
    - one lost reply is no longer mistaken for the wrong firmware;
    - a drop cut off by a disconnect no longer haunts the next connection;
    - a double-pressed Spread no longer adds a phantom history line;
    - Disconnect aborts a drop that's still sending;
    - the tune readout says "+2.5 st".
- **Each key has an amp envelope and a choke group** (Kit row, or the new
  **⋯** corner on each Play pad, which opens the same controls in a sheet
  without playing the pad):
  - Attack 0–2 s;
  - Decay 0–4 s down to a Sustain of 0 to −59 dB, or off;
  - Release 0–4 s;
  - choke group none or 1–4: an open hat is cut by a closed one in the same
    group.

  All zero sounds exactly as before. A spread copies the envelope and the
  group.
- **Held memory comes back (Reclaim):**
  - a **Reclaim n s** button (Play's pads row, Kit's buffer) takes back
    what replaced and cleared pads still hold. It asks only if Undo would
    lose steps.
  - a drop that doesn't fit reclaims by itself first and then lands whole.
  - **Save set** writes only what plays, packed, and costs no undo steps.
  - Pads keep sounding through a reclaim, held, looping or ratcheting.
  - A reclaim copies up to ~17 MB (a few hundred ms, unmeasured).

Tests: host suite all green (reclaim_check 99, keyp_check 186+), page selftest
814. SRAM is at **96.9 %** (14.6 KB left), so the next features have to be
small or something has to give.

## Calls (the defaults are what's built)

- **Release on one-shots** does nothing. A one-shot is shortened with Decay
  + Sustain off instead. Make Release fade a one-shot's natural end?
- **Release is a rate** (60 dB in its time from full), not a time from
  wherever it starts.
- **Pattern steps** neither choke nor get choked. Should a hat step cut a
  grouped open hat?
- **Spreading a grouped key** makes the spread monophonic.
- **The ⋯ target** is 28 px; on a phone it squeezes the pad's small line.
- **Reclaim:**
  - a drop doesn't ask before forgetting undo steps;
  - the button doesn't try the undo-safe reclaim first;
  - takes into keys never reclaim on their own;
  - a trimmed pad's cut edges count as held.
- Still open from 10-26: ▶ in Pads brings back the beat; ratchet without a
  gate fills a 16th; the spread's defaults.
